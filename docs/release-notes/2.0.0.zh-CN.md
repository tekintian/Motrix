# Motrix 2.0.0

English | [简体中文](https://gitee.com/tekintian/Motrix/blob/v2.0.0/docs/release-notes/2.0.0.zh-CN.md)

Motrix 2.0.0 稳定版发布。新增 HLS 自动检测功能和 NDM 广告过滤扩展集成。

## 新特性

- **aria2 RPC HLS 自动检测**: `aria2.addUri` 现在自动检测 `.m3u8` URL, 改用 `aria2c` 命令行下载 (原生支持 HLS: 解析 m3u8 → 多连接下载分片 → 合并为一个文件)
- 兼容 [NDM AdFilter 扩展](https://gitee.com/tekintian/neat-download-manager) — 扩展发送去广告后的 m3u8 到 Motrix 下载合并

## 修复

- package.json 版本与 release tag 对齐
- Flatpak AppStream metainfo release 顺序修正
- Fork 构建跳过 Gitee tag protection ruleset 检查

## 内部

- `aria2-rpc-client.ts` 的 `addUri` 方法增加 HLS URL 检测
- 移除冗余的 `motrix-hls-hook.js` (已集成进 RPC client)
