# 2.0.0

## Features

- **HLS auto-detection in aria2 RPC**: `aria2.addUri` now detects `.m3u8` URLs and uses `aria2c` command line (native HLS support: parse → multi-connection download → merge) instead of downloading the m3u8 text file itself.
- Compatible with [NDM AdFilter extension](https://gitee.com/tekintian/neat-download-manager) — sends cleaned m3u8 (ad-filtered) to Motrix for download.

## Fixes

- Package version aligned with release tag.
- Flatpak AppStream metainfo release order corrected.
- Release-metadata ruleset check relaxed for fork builds.

## Internal

- `aria2-rpc-client.ts` `addUri` method now checks for HLS URLs before forwarding to aria2 RPC.
- `motrix-hls-hook.js` standalone module removed (integrated directly into RPC client).
